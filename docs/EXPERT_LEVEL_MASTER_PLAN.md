# MathDigitizer — Мастер план за експертско ниво (v1, 2026-08-22)

Сеопфатен план за затворање на **сите наоди** од трите длабински анализи (12 области)
и издигнување на апликацијата на професионално/експертско ниво.
База на наодите: сесиски анализи од 22.08.2026 (агенти за extraction/kahoot/OCR,
whiteboard/student/exams/flashcards/mindmaps, factory/analytics/graphs/curriculum).

## Принципи (без компромиси)

- **PRODUCT_RULES.md** важи за секоја фаза: педагогија прво, RAG прво, доказ наместо
  погодување, вистински контролни точки, минимални повратливи едити каде што има
  неизвесност, без враќање на постоечка работа.
- **Верификација по СЕКОЈА фаза**: `npm run lint` → нови unit тестови →
  `npm run test:smoke` → e2e каде што е означено → `npm run quality:gates` →
  **локален комит, без push** (push само со експлицитна потврда).
- **Без нови зависности** освен ако е експлицитно оправдано во фазата.
- Секој AI излез што стигнува до Firestore или до UI минува валидација
  (форма + математика) — системска правила, не ad-hoc.

   го растура додека работи. Затоа распоредот е дејство (`autoLayout.ts`,
   детерминистички — двапати притиснато дава исто), не режим.
   `graph.ts` држи една инваријанта: ниту една врска не именува јазол што го
   нема. Висечка врска не фрла грешка — се исцртува како линија кон нулата, па
   мапата тивко добива поврзување што наставникот никогаш не го нацртал.
   `repairMap` се пушта при вчитување: наставник чија мапа не се отвора ја
   загубил работата, наставник на кој му недостига една лоша врска загубил
   една врска и гледа која.
   Извозот гради SVG стринг наместо да го стрга DOM-от — испечатената мапа не
   треба рачки за влечење, а стрингот е тестибилен. Секој натпис што го напишал
   наставник се escape-ира: неescape-иран `&` дава фајл што ниту еден
   прегледувач не го отвора, а неescape-иран `<` дава фајл што повеќе не е само
   слика, бидејќи PNG конверзијата го носи SVG-то низ `<img>`.
   БРО кодовите на јазол ги става само човек — §3.

## ФАЗА 12 — Напречно зацврстување (континуирано во секоја фаза + финален премин)

- aria/ролови ревизија (tablist, progress bars, canvas), e2e проширување,
WCAG 2.1 премин, i18n 100% за сите touch-точки што ги менуваат фазите. ✅

**Измерено, не претпоставено.** Сировото скенирање пријави 34 копчиња само со
икона без пристапно име; по внимателна детекција — **нула**. Речиси сите веќе
носат `{t('…')}` како содржина, што хеуристиката го бришеше. Најдено и
поправено: едно `<canvas>` без име (`smart-ocr/ImageCropPanel`).

**i18n:** 591 тврди македонски низи низ целата апликација, но планот бара само
допирните точки на фазите — таму 10 од 47 компоненти, 101 линија. Две од нив беа
експлицитни ставки од претходни фази што не слетаа целосно:
`live/GamePlayer` (ставка 2.4) немаше `useTranslation` воопшто, а
`TeacherExamsDashboard` (ставка 5.5) беше преведен само делумно. Сега сите на
mk/en/al. Останатото што скенерот го пријавува се коментари, интерни клучеви
што се праќаат на моделот (не смеат да се преведат) и DEV-фикстури.

**e2e:** нов `accessibility.spec.ts` — WCAG проверки директно врз DOM-от, без
нова зависност: пристапно име на секоја контрола, ознака на секое поле, `alt`,
уникатни `id`, `lang`. Гејтираните екрани преку probe рути, како постоечкиот
образец. Кога сите 9 поминаа од прв обид, напишав мета-тест што докажува дека
проверувачот не е празен: испитува 6 контроли на таа страница и го фаќа
намерно вметнато неименувано копче. 70 e2e теста поминуваат.
