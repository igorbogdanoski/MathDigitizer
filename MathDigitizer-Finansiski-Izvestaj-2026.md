## 1. ИЗВРШНО РЕЗИМЕ

**MathDigitizer Pro** е прва македонска платформа за AI-поддржана **дигитализација на математиката** — систем кој го трансформира аналогниот наставен процес (PDF, слики, видеа, ракопис) во структурирани дигитални содржини усогласени со македонскиот К–12 курикулум.

Платформата не е само „AI генератор" — таа е **целосен педагошки екосистем**: од дигитализација на постојните материјали, преку live интерактивни часови, до автоматизирано оценување и аналитика по ученик.

## 2. ТЕКОВНА СОСТОЈБА НА ПЛАТФОРМАТА

### 2.1 Општо

MathDigitizer Pro е **Production-ready SaaS** апликација — не прототип. Целосно развиена платформа со:

- **Zero TypeScript compilation errors** — индустриски стандард за производниот код
- **100% тест минување** — сите тестови поминуваат (7/7)
- **Успешен build + deploy** — апликацијата е деплојана на Vercel CDN и Hostinger
- **Offline режим (PWA)** — работи без интернет, критично за рурални средини
- **Mobile-first** — целосно функционална на мобилни уреди
- **Sentry error tracking** — production мониторинг во реално време
- **GA4 аналитика** — user-scoped аналитика со role + pro сегментација
- **WCAG 2.1 AA пристапност** — сите интерактивни елементи имаат `aria-label`; форми се поврзани со `htmlFor/id`; поддршка за screen readers
- **QR код за Kahoot** — наставникот ги покажува и PIN и QR код на проектор; учениците се приклучуваат со скенирање без пишување
- **Сет за конверзија** — sticky CTA за незалогирани посетители, подобрен empty state во Библиотека со директен CTA кон Екстракција

### 2.2 Уникатна вредносна понуда

**MathDigitizer Pro е единствена платформа во Македонија која:**

## 3. ФУНКЦИОНАЛЕН ИНВЕНТАР ПО МОДУЛИ

### 3.1 Дигитализација и Екстракција (Extraction Engine)

**Ова е јадрото на платформата — нема аналог во Македонија.**

| Извор | Процес | Резултат |
|---|---|---|
| **PDF тест/учебник** | Gemini 3.1 Pro OCR + логичка реконструкција | Структурирани задачи со решенија, LaTeX, DoK |
| **Фотографија** (телефон) | Multimodal AI анализа | Задачи со solution steps и hints |
| **YouTube видео** | Gemini audio transcript → задачи | Задачи со timestamp reference |
| **Ракопис** | Smart OCR + контекстуална корекција | Дигитализиран математички текст |
| **Word/DOCX** | Mammoth parser + AI | Задачи со форматирање |

**Клучна карактеристика**: Системот AUTO-ДЕТЕКТИРА јазикот на изворот (MK/SQ/TR/EN/AR/...) и ги враќа задачите на **оригиналниот јазик** — не преведува.

**Evidence quotes** — Anti-hallucination систем: секоја задача содржи дословен цитат од изворот (`evidence_quote`) и временска ознака (`source_timestamp`), за да наставникот може да го верифицира.

|---|---|

| **Webb's DoK** | Секоја задача носи `dok_level` (1–4), аналитика по ниво |

| **МОН компетенции** | Директно mapping на кодови (МА.X.X.X) во curriculum factory |

> **Аргумент за БРО**: MathDigitizer не е само „AI генератор" — е педагошки систем усогласен со националните образовни стандарди. Секоја задача е означена по Bloom и DoK, а Curriculum Factory генерира директно по официјалните кодови на МОН компетенции.

## 10. ОНА ШТО НЕДОСТАСУВА ЗА ПОЛНА КОМЕРЦИЈАЛНА ПОДГОТВЕНОСТ

### Приоритет А — Критично за продажба (1–3 месеци)

1. **Автоматско онлајн плаќање** — Stripe и PayPal не се достапни за македонски merchant accounts. Тековно: директен банкарски трансфер (со референца) + рачна admin активација. Решение за нареден квартал: `Nexi` (НЛБ) или `iPay` (КБ) — македонски payment gateway-и кои работат со Visa/MasterCard домашни картички.

2. **Автоматска bulk-license активација** — School plan моментално бара рачна активација на секој наставник. Потреба: Email invite → auto-Pro активација.

3. **Onboarding Email Flow** — Нема автоматска welcome email секвенца, trial expiry reminders, onboarding checklist. Потреба: Resend.com (€20/мес.) + автоматски flow.

4. **Usage counter** — „Колку дигитализации денес / овој месец?" видливо во интерфејсот за Free корисниците (конверзионо движење кон Pro).

### Приоритет Б — Важно за раст (3–6 месеци)

5. **Мобилна апликација** (iOS/Android) — Моментално PWA (инсталабилна, но не native). Native app е критично за ученичкиот segment. Решение: React Native (70% code reuse).

6. **Parent Portal** — Read-only линк за родители (неделен напредок). Потенцијален freemium приход: 200–500 МКД/год per parent.

7. **EMIS / е-Дневник интеграција** — Ако МОН го бара, потребна е API интеграција со националниот е-Дневник.

8. **Повеќе предмети** — Моментално: само математика. За School Pro да биде максимално вредно, треба: физика, хемија, биологија. Ова ги утројува корисниците на School план.

### Фаза 2 — Регионална Лиценца (12 месеци)

**Механизам**: Општинска буџетска ставка (просветен фонд)

**Ценовен модел за општини**:
- По ученик: 300 МКД / ученик / год

### Фаза 3 — Национална Лиценца (МОН)

**Аргументи за МОН**:
